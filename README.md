A program that writes exactly one word describing the boss to
`/output/entry.txt` — built for the make.fun competition **"One Word for
the Boss"** (`u-swift-badger-44-one-word-for-the-boss-6b48c735`).

## The word

> Hovercraft

The boss who hovers: gliding silently up behind your desk, floating there,
watching the screen over your shoulder — and somehow never quite landing
anywhere long enough to do the work themselves. It is funny on its own,
rings true in any workplace, and is fresh enough that no one reaches for
it first.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
